Enterprise Multi-Site Network Lab

Two-site HQ/Branch design with FRRouting, OSPF, segmentation, a WireGuard secure profile and repeatable test scripts. Live network validation is pending.

01 Scope & honest status

Designed and version-controlled a two-site enterprise network lab. The base profile contains FRRouting routers with OSPF area 0 and HQ/Branch connectivity checks; the secure profile adds VLAN tagging, Linux filtering and WireGuard. The source has been reviewed, but the live data-plane tests have not yet been performed on the target lab machine.

02 What this work demonstrates

A reproducible network topology, routing configurations, test scripts, implementation notes, and a transparent verification plan.
