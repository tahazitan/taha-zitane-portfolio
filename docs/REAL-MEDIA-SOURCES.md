## Before importing a real picture

1. Find the original vendor or creator page and verify permission to reuse the image (including in a public portfolio).
2. Store the original source URL, author, license, attribution requirements, and permitted transformations in this register.
3. Download or receive the actual image asset. Avoid hotlinked, unstable or unlicensed thumbnails.
4. Label vendor product photography as *representative product imagery*, not equipment the portfolio owner physically deployed.
5. For GNS3 screenshots, use a real exported .gns3 topology / screenshot and confirm the visible links and appliance names match that GNS3 project.
6. Optimize media for web (AVIF/WebP where appropriate); include accurate alt text and responsive sizes; never artificially manufacture screenshots.
7. Redact customer IPs, keys, usernames, organizations and privileged configurations.
8. For live lab proof, publish date, environment, command/test and measured output, and label it as verified only after review.
