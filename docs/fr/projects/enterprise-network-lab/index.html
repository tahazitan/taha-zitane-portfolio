// INGÉNIERIE RÉSEAUX / CASE 01

Lab réseau d'entreprise multi-sites

Maquette HQ/Branch avec FRRouting, OSPF, segmentation, profil sécurisé WireGuard et scripts de tests reproductibles. Validation réseau réelle à venir.

FRRoutingOSPF802.1QWireGuardLinux

01 Périmètre et statut réel

Conception et versionnement d'un laboratoire réseau multi-sites. Le profil de base utilise FRRouting/OSPF area 0 et des tests siège/agence ; le profil sécurisé ajoute VLAN, filtrage Linux et WireGuard. Code revu, mais les tests de connectivité réels n'ont pas encore été exécutés sur la machine cible.

02 Ce que ce travail montre

Topologie reproductible, configurations, scripts de test, procédures et plan de validation transparent.

03 Étapes de validation

  1. 01Déployer le profil de base dans une VM Linux avec Docker et Containerlab.
  2. 02Valider l'adjacence OSPF Full et les routes apprises.
  3. 03Collecter des preuves de ping, rupture WAN et rétablissement.
  4. 04Tester VLAN, pare-feu et WireGuard du profil sécurisé.
