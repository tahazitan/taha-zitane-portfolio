// هندسة الشبكات / CASE 01

مختبر شبكة مؤسسية متعددة المواقع

تصميم شبكة تربط المقر والفرع باستعمال FRRouting وOSPF وتقسيم الشبكة وWireGuard وسكريبتات اختبار قابلة للإعادة. التحقق الفعلي ما زال قيد الإنجاز.

FRRoutingOSPF802.1QWireGuardLinux

01 النطاق وحالة التنفيذ الفعلية

تصميم وتوثيق مختبر شبكة مؤسسية بموقعين. يستخدم النموذج الأساسي FRRouting وOSPF area 0 مع اختبارات اتصال بين المقر والفرع، بينما يضيف النموذج الآمن VLAN وفلترة Linux وWireGuard. روجع المصدر، ولم تُنجز اختبارات الاتصال الحقيقية بعد على الجهاز المستهدف.

02 ماذا يثبت هذا العمل؟

تصميم قابل لإعادة التنفيذ وإعدادات توجيه وسكريبتات اختبار وإرشادات تشغيل وخطة واضحة لتوثيق النتائج.

03 خطوات التحقق المقبلة

  1. 01تشغيل النموذج الأساسي في Linux VM باستخدام Docker وContainerlab.
  2. 02التحقق من OSPF Full والمسارات المتعلّمة.
  3. 03جمع أدلة Ping وانقطاع الربط بين الموقعين واستعادته.
  4. 04اختبار VLAN وقواعد الجدار الناري وWireGuard في النموذج الآمن.
