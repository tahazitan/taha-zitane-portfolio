Self-hosted vector technology logos are displayed in context across the portfolio's hero, project cards, case studies, experience, and capabilities. They represent technology names, not vendor endorsements or certified credentials.

- Cisco, Linux, Ubuntu, Debian, Proxmox, Docker, Fortinet, Palo Alto Networks, Wireshark, Snort, and GitHub: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0.
- Windows mark: [Devicon](https://github.com/devicons/devicon), MIT.
- Wazuh mark: [Wazuh Dashboard](https://github.com/wazuh/wazuh-dashboard/blob/main/src/core/server/core_app/assets/logos/wazuh_mark.svg), Wazuh trademark. See repository licensing; keep branding accurate.
